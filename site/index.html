The simple version

Ask once.
Zhunt finds a model that can answer.

01

Add free keys

Groq, Google AI Studio and Cerebras give free API keys. Paste one in a terminal with zhunt keys add groq; it never touches a web page.

02

Ask anything

Zhunt reads the request on your machine, decides if it is chat, code, long-context or reasoning, and picks the healthiest free model with quota left.

03

Never hit a wall

When a model runs out, zhunt rests it and retries on the next one before you see an error. Every reply says which model answered and why.

The provider boundary

Your prompts stay between you and the model.

Zhunt runs on your computer. It classifies requests locally and sends them straight to the provider it picks. There is no zhunt server in the middle, and zhunt does not phone home, not even to check your licence.

Some free tiers may train on prompts. Zhunt skips those providers unless you opt in, and labels them everywhere.

⌁Local by default
  • Provider keys live in ~/.zhunt/env with owner-only permissions.
  • Prompts and responses are never logged; telemetry stays on your machine.
  • Licence keys are verified offline.
  • Open source: read every line.

Install in a minute

One command. Then add a free key.

Zhunt is a Python app. uv installs it and keeps it isolated; it works the same on macOS, Windows and Linux.

uv tool install git+https://github.com/loopeywho/zhunt
zhunt keys add groq      # free key from console.groq.com
zhunt serve              # starts zhunt on this computer
zhunt open               # opens your workspace

Free keys: Groq, Google AI Studio, Cerebras. One key per provider, under that provider's terms. Preview software: tell us what breaks.

Trust, cancellation, and billing

Keep control of your data and spend.

Zhunt cannot see your card number, provider keys, prompts or responses. The provider zhunt routes a request to receives it, as it would if you used that provider directly. Premium usage is billed by that provider and capped by the monthly limit you set.

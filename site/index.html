Install

One command. Then add a free key.

terminal
# needs uv: https://docs.astral.sh/uv
uv tool install git+https://github.com/loopeywho/zhunt
zhunt keys add groq      # free key from console.groq.com (or paste it in the app)
zhunt serve              # starts zhunt on this computer
zhunt open               # opens your workspace

Free keys: Groq, Google AI Studio, Cerebras. One key per provider, under that provider's terms. Preview software: tell us what breaks.

Questions

Good to know

Is it really free?

Yes. Zhunt uses the free tiers that AI providers offer (Groq, Google, Cerebras and others) with your own free keys, and moves to the next one when a limit is reached. You only pay if you choose Pro and add a paid key for premium models.

Can zhunt see my prompts?

No. Zhunt runs on your computer and sends each request directly to the provider it picks; there is no zhunt server in between. That provider receives your prompt under its own terms, as if you used it directly.

Do any free providers train on my prompts?

Some free tiers say they may. Zhunt labels them and keeps them off unless you switch them on, which adds capacity (including a provider that needs no key at all).

Do I need to know how to code?

No. You run one install command once; everything else happens in the app, including adding keys.

What does Pro add?

When every free model is busy, Pro steps up to a premium model (Claude, GPT or Gemini Pro) using your own paid key, under a monthly spending cap you choose. Everything else is free.

How do I cancel?

Any time before renewal, from the billing link in your Stripe receipt. Pro keeps working to the end of the paid period, and the free version keeps working after that.

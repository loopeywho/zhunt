zZhunt

Setup guide

Start the Zhunt desktop preview.

Zhunt runs on your computer and opens a workspace in your browser. The v0.2.0.dev0 Mac and Linux portable previews bundle Python: no separate Python or uv install is needed.

1. Download and start the portable preview

  • Mac Apple Silicon (arm64): download Zhunt-Portable-macos-arm64.tar.gz, extract the whole archive and open zhunt/Zhunt.command.
  • Linux x86_64: download Zhunt-Setup-linux-x64.tar.gz, extract it and run ./zhunt/Start-Zhunt.sh in a terminal. Built on Ubuntu 22.04 WSL2 / glibc 2.35; requires glibc 2.35 or newer.

The launcher starts a loopback-only service and opens the workspace in your browser. Keep the launcher terminal open; Ctrl+C stops it. Once the workspace opens, skip the source alternative below and continue to step 3.

Check the download with its matching Mac SHA-256 sidecar or Linux SHA-256 sidecar in the download directory: on macOS use shasum -a 256 -c ARCHIVE.sha256; on Linux use sha256sum -c ARCHIVE.sha256, replacing ARCHIVE.sha256 with the downloaded sidecar filename.

Preview limitations: unsigned and not notarized. Gatekeeper/quarantine approval flows and automatic browser handoff have not been certified; browser rendering was checked separately. No native Mac PKG/DMG is published; installation/uninstallation was not validated. Intel Mac, native Linux browser integration, browser terminal keyboard interaction, upgrade/uninstall lifecycle and full provider/chat/agent execution are not certified. Linux verification used WSL2, not a native graphical Linux desktop. No provider calls were made in these tests; startup verification is not full product certification.

No Windows binary is included or advertised as tested in this release; integrated Windows terminals remain unsupported. Android and iOS are under development, with no mobile downloads. See the exact v0.2.0.dev0 release notes and verification scope.

2. Source installation (alternative, not needed for portable downloads)

For the source alternative, install uv, then explicitly select Python 3.12:

uv tool install --python 3.12 git+https://github.com/loopeywho/zhunt

Check it worked: zhunt --help prints the list of commands. Start the source installation with:

zhunt serve     # leave this running
zhunt open      # in a second terminal: opens the workspace in your browser

For a source installation, open the workspace with zhunt open. It passes the workspace its key in a way your browser never sends anywhere. A tab opened by hand says "This workspace needs its key"; that is expected.

If port 4000 is busy, zhunt picks another and remembers it. zhunt open always finds it. See the source getting-started guide. Commands below using zhunt assume this source installation; portable users can use the workspace controls.

3. Add one free key (optional, one is enough)

zhunt answers straight away with no key at all, through a free provider that does not train on your prompts. It is slow and its limits are shared by everyone, so the workspace will suggest one free key for speed.

  • Groq (recommended, about a minute, no card): console.groq.com/keys
  • Later, only if you hit limits: Google AI Studio, Cerebras and the others under More free capacity in the app.

In the workspace, open the Connect window and paste the key in the Paste any key box: zhunt tells which provider it is for. Or in a terminal: zhunt keys add. Keys stay on your computer, in a file only you can read, and are never shown again.

4. Ask something

Type in the chat window. Zhunt picks the best free model that has room, and moves to another one by itself when a provider is busy. The routing window shows which model answered and why.

Some free providers say they may use prompts for training. They stay off unless you turn on the switch in the Connect window.

5. Use zhunt from your other apps (optional)

zhunt launch codex     # starts Codex with zhunt as its model provider
zhunt launch hermes    # the same for Hermes
zhunt launch cursor    # Cursor and VS Code: prints the steps for their settings

Nothing in the app's own config files is changed, so app updates cannot break the connection.
